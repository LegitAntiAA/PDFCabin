# web/ — placeholder

This folder currently contains a **placeholder** page only, so that `docker
build` and the static mount in `app/main.py` work before the real UI lands.

The real web UI (`index.html`, `app.js`, `style.css`, `logo.svg`,
`favicon.svg`) is built by a separate neural network according to section 7 of
the master plan and **replaces everything in this folder**. The placeholder
files can be deleted without a second thought.

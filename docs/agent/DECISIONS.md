# DECISIONS.md — операционные решения PDFCabin

Решения принимает Root; споры закрываются тестами/доказательствами. Архитектурные — см. комментарии в коде.

- **D-001 (2026-11-09): Tesseract/GS через micromamba+conda-forge в user-dir.** UB-Mannheim и Ghostscript-инсталляторы требуют админа (тихий запуск молча откатывается), innoextract 1.9 не берёт новый InnoSetup. micromamba (одиночный бинарник) + conda-forge tesseract 5.5.3 + tessdata_fast rus/eng + ghostscript — полностью без админа. Приложение находит их через PATH + TESSDATA_PREFIX (для docker/CI — родные apt-пакеты по спеке).
- **D-002: fastmcp 4.x API.** План писался под fastmcp 2.x (`streamable_http_app()`), pip в 2026-11 ставит 4.1.6, где этот метод удалён. В main.py fallback: `mcp.http_app(transport="streamable-http")` (возвращает StarletteWithLifespan — lifespan-трюк из 4.1 спеки сохраняется). Дополнительно интроспекция `getattr(mcp_app, "lifespan", ...)`.
- **D-003: DELETE /api/file?path= добавлен сверх таблицы 6.6.** UI (7.1.2) требует Delete (перемещение в trash/), но REST-таблица спеки эндпоинта не содержала — внутренний пробел спеки. Перемещает в docs_dir/trash/, чистит поисковый индекс. Зафиксировать как отклонение в task.md; включён в README (агент уведомлён).
- **D-004: docs_url/redoc_url отключены.** Swagger UI тянет ассеты с CDN — нарушает «ноль исходящих запросов». openapi.json остался (локальные данные). Упомянуть в task.md.
- **D-005: Docker HEALTHCHECK бьёт в «/», а не в /api/health.** /api/health намеренно защищён токеном (тест 9 спеки), с токеном контейнер был бы вечно unhealthy. Отклонение от черновика раздела 8, передано агенту-DevOps, зафиксировано в Dockerfile комментарием.
- **D-006: токен на /mcp через собственный ASGI-миддлварь**, а не классы auth fastmcp (те целятся в OAuth-флоу, нам нужен простой Bearer). Версионно-устойчиво.
- **D-007: локально docker build выполнить нельзя (docker отсутствует).** В DoD будет помечен «Not executed» с причиной; CI-job docker-build добавлен, отработает на GitHub. Честно в отчётах.
- **D-008 (руководящее): дисциплина AGENTS.md.** Отчёты Telegram каждые ~10 мин активной разработки + docs/agent-трекинг; имплементация/отладка/верификация — через субагентов (Engineers, Debugger, QA, Reviewer), Root — координация, интеграция, мелкие точечные фиксы.
- **D-009: GET /api/jobs возвращает ВСЕ джобы** (активные первыми, затем завершённые), а не только активные. Спека внутренне противоречива: 6.6 говорит «активные джобы», но панель задач UI (7.1.3) обязана показывать и завершённые (кнопка Download результата). Код разрешает противоречие в пользу UI; формулировки в README×2 поправлены (находка Reviewer MINOR-1).
- **D-010 (по ревью): релизные хвосты README** — GIF-демо при финализации поставить на заметное место (после Why, не внутри Screenshots); docker-бейдж заменить на pulls после публикации образа; донат-плейсхолдеры заполняет владелец (EN: <TO-BE-FILLED-BY-OWNER>, RU: <ЗАПОЛНИТЬ>). Пункт чек-листа релиза, не блокер v0.1.
- **D-011 (2026-11-10, решение владельца): донат-адреса вшиты в конфиг как дефолты.** Владелец: «локальный запуск тоже должен показывать мои адреса всегда». Изначально вшиты биржевые адреса (BTC/ETH ERC-20/USDT BEP-20/USDT TRC-20), затем владелец заменил их на некастодиальные (BTC bc1…, Ethereum-адрес для ETH+USDT ERC-20, USDT TRC-20, TON) — биржевые кошельки убраны (риск бана за приём донатов), BEP-20 слот удалён. `PDFCABIN_DONATE_*` env перекрывает дефолты (fork-паттерн жив). README×2 (Donate + Configuration) и compose-комментарии синхронизированы. Крипто-адрес — публичные данные, в репо допустимы; приватные ключи — никогда.
- **D-012 (2026-11-10, решение владельца): MCP расширен с 8 до 15 тулов.** Владелец: «загружать/выгружать/изменять — это же база». Новые тулы: upload_document (с пути ОС), create_document (текст→PDF, кириллица через найденный unicode-шрифт), save_document (на путь ОС), delete_document, rename_document (+rename_in_index в FTS), pdf_rotate, pdf_delete_pages. Обмен файлами через пути ОС, НЕ base64 (владелец: агент локален; base64 раздувал бы контекст). Новый app/services/library.py — общий слой REST+MCP; api.py переведён на него с неизменными формами ответов (контракт web_task.md). reportlab перенесён в основные зависимости (create_document — прод-код). Spec 6.7 «ровно 8 тулов» superseded.
